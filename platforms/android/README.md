# 漫剧制作记 - Android 版本

## 构建方式
需要 Android Studio + Capacitor/Cordova 或 electron-forge 的 Android 插件

```bash
npm run build -- --platform=android
# 输出目录: dist/android
```

## 包信息
- 包名: com.liuliu.manjufactory
- 版本: 1.2.0

## API 配置
- 端点: https://api.agnes-ai.cn/v1
- 文本模型: agnes-2.5-flash
- 视频模型: agnes-video-v2.0
